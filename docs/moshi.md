# Moshi mobile terminal

Moshi is an optional mobile terminal and agent-control surface. It does not
replace SSH, Mosh, Herdr, Tailscale, or the host-side coding agents; those stay
on the MacBook Pro or LFG Laptop Herdr.

## Two-host setup

The free tier supports two saved connections. Use those for the coding hosts:

1. **MacBook Herdr**: macOS user, the Mac's Tailscale IP or MagicDNS name, and
   an SSH key generated by Moshi. Select Mosh after Remote Login and the Phase
   9 Mosh-host preparation are complete.
2. **LFG Laptop Herdr**: Windows MSYS2 user, the laptop's Tailscale IP or
   MagicDNS name, and a separate Moshi-generated SSH key. Select Mosh after
   the existing MSYS2 SSH/Mosh host and the Tailscale-scoped firewall rules
   have been configured.

Do not copy a private SSH key into the repository. Add only the public key
that Moshi displays to each host's `authorized_keys` file through that host's
approved setup process.

Moshi uses Tailscale as ordinary private network transport: enable Tailscale
on the phone, then enter the host's Tailscale name or address as a normal
connection target. No router port forwarding is required. See
[Tailscale remote access](tailscale.md) for the host prerequisites.

## Optional macOS Moshi hook

`moshi-hook` is optional. Basic SSH/Mosh terminal access and starting Herdr do
not require it. The hook provides agent notifications, approvals, and richer
live Herdr awareness in Moshi.

To install or verify only the macOS binary:

```bash
./setup.sh --moshi-hook --install-missing
doctor --phase moshi
```

The setup command may add Moshi's documented Homebrew tap and install the
`moshi-hook` formula. It does **not** pair the Mac with the phone, start a
background service, or alter Codex/Pi configuration.

Some Homebrew versions require an explicit trust decision before loading a
formula from a third-party tap. If setup reports that requirement, review the
formula and run this once yourself, then rerun setup:

```bash
brew trust --formula rjyo/moshi/moshi-hook
```

The repository never grants tap trust automatically.

After installation, in Moshi open **Settings -> Hooks**, copy the pairing
token, and run these commands manually on the intended Mac:

```bash
moshi-hook pair --token '<token copied from Moshi>'
moshi-hook install
brew services start moshi-hook
```

`moshi-hook install` changes Moshi-owned configuration entries for supported
agents, including Codex and Pi. Review that change on the individual machine.
The pairing token and resulting host state are credentials/local state: never
put them in this repository, a checked-in config file, or a shell history you
do not control.

If you only want terminal access and the Herdr workspace picker, stop after
adding the saved connections and validating SSH/Mosh. Add the hook later when
you want Moshi notifications or agent controls.
